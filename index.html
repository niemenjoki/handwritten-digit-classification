Simply draw a digit on the canvas with your mouse or finger!

The neural network tries to guess which digit you drew.

For example, if you see this:


the neural network thinks you most likely drew a 1 and possibly a 7.

An old learning project from 2019. The neural network is written in plain JavaScript and was trained on about 14 000 handwritten digits drawn by more than 200 volunteers.

In 2026 the bugs in the network were fixed and the dataset was cleaned. The menu under the canvas switches between the 2019 network, the fixed one and a TensorFlow.js comparison model.

The code and the dataset are on GitHub. More about me: niemenjoki.fi.
